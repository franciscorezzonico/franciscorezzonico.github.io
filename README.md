# Francisco Rezzonico — Data & Analytics Portfolio

Personal portfolio website for Francisco Agustín Rezzonico, a data analyst and MS in Business Analytics & AI candidate at American University.

**Live site:** [franciscorezzonico.github.io](https://franciscorezzonico.github.io/)

## About

This site presents my professional background, selected analytics projects, technical skills, and contact information. It is designed as a responsive, single-page portfolio with a dark visual theme, custom cursor effects, scroll-reveal animations, and an animated analytics workflow visualization.

## Featured projects

- **Spotify Music Market Analysis:** Exploratory analysis of 9,227 Spotify tracks using R, `ggplot2`, and Plotly.
- **Manhattan Private-Room Pricing Analysis:** Reproducible R and Quarto workflow using multiple linear regression, model diagnostics, exploratory visualizations, and an interactive 3D Plotly chart.
- **EV CAFV Eligibility Analysis:** Statistical analysis of 103,032 Washington State EV registrations using a chi-square test, Cramér's V, and data visualizations.

## Local preview

No build step is required. Clone the repository and open `index.html` in a modern web browser.

```bash
git clone https://github.com/franciscorezzonico/franciscorezzonico.github.io.git
cd franciscorezzonico.github.io
```

For the most reliable local-development experience, serve the folder with a lightweight local server. For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Deployment

The portfolio is deployed through GitHub Pages from the `main` branch and the repository root. Changes pushed to `main` are automatically published to the live site.
